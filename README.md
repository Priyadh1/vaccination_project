# Vaccination Data Analysis and Visualization

## Project Overview

This project focuses on analyzing vaccination and disease-related data using Python, SQL, and Power BI.

The project studies vaccination coverage, disease incidence, reported cases, vaccine introduction, and vaccination schedules to understand vaccination trends, disease patterns, and differences across countries and regions.

## Project Type

**EDA (Exploratory Data Analysis)**

## Contribution

## Objectives

- Clean and prepare vaccination-related datasets.
- Analyze vaccination coverage and disease-related trends.
- Study differences across countries and regions.
- Perform statistical and correlation analysis.
- Organize the data using a normalized SQL database.
- Create a Power BI dashboard to present the main findings.
- Answer the given business and scenario-based questions using the available data.

## Datasets

The project uses five datasets:

1. Coverage Data
2. Incidence Rate Data
3. Reported Cases Data
4. Vaccine Introduction Data
5. Vaccine Schedule Data

The datasets contain information covering different years, countries, vaccines, and diseases.
